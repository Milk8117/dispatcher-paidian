## 一、产品愿景

### 1.1 核心理念

**每个人的生活都应该有一个"AI中枢"**——它不是某个APP的功能插件，而是一个真正理解你、管理你、服务你的私人智能系统。

当前市场上的AI产品（Siri、小爱同学、Alexa）都是**被动响应型工具**，用户必须主动发出指令。我们的目标是构建一个**主动决策型AI OS**：

| 维度 | 传统AI助手 | 个人AI OS |
|------|-----------|-----------|
| 交互模式 | 被动响应指令 | 主动推送决策 |
| 数据孤岛 | 每个APP各自独立 | 统一数据底座，跨模块联动 |
| 智能程度 | 单点功能（查天气、设闹钟） | 关联分析（根据健康+天气+节气推荐行动） |
| 数据归属 | 云端存储，用户无法掌控 | 100%本地存储，隐私优先 |
| 扩展性 | 封闭生态 | 模块化架构，按需组装 |

### 1.2 一句话定位

**数据100%自留的个人AI操作系统，从财务到健康到日程，一个入口管理所有生活维度。**

### 1.3 终态愿景（5-10年）

构建用户的**数字孪生体**——AI不仅理解你的数据，还能代替你处理日常决策：
- 自动分析财务趋势，主动预警风险
- 根据身体状况推荐今日饮食和运动
- 管理智能家电，根据作息自动调控环境
- 跨平台信息整合，成为你的信息中枢

## 二、系统架构

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────┐
│                   表现层 (UI Layer)                    │
│   PWA SPA · 模块化Tab架构 · SVG线性图标体系           │
├─────────────────────────────────────────────────────┤
│                  智能决策层 (AI Layer)                  │
│   意图识别引擎 · 主动推送引擎 · 跨模块关联分析          │
├─────────────────────────────────────────────────────┤
│                  业务模块层 (Module Layer)              │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐      │
│  │财富CT│ │日常  │ │节气  │ │日程  │ │行为  │      │
│  │诊断  │ │收支  │ │养生  │ │管理  │ │日志  │      │
│  └──┬───┘ └──┬───┘ └──┬───┘ └──┬───┘ └──┬───┘      │
│     │        │        │        │        │           │
│  ┌──┴────────┴────────┴────────┴────────┴──┐       │
│  │         待扩展：智能家电控制模块           │       │
│  └─────────────────────────────────────────┘       │
├─────────────────────────────────────────────────────┤
│                  数据底座层 (Data Layer)               │
│   DataStore统一访问层 · localStorage → IndexedDB     │
│   导入/导出全链路 · 数据完全本地化                      │
├─────────────────────────────────────────────────────┤
│                  基础设施层 (Infra Layer)              │
│   PWA离线缓存 · Service Worker · 提醒引擎             │
└─────────────────────────────────────────────────────┘
```

### 2.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | 原生JS (Vanilla) | 零依赖，极致轻量，加载速度<1s |
| 样式系统 | 纯CSS3 | 无预处理器依赖，CSS变量主题系统 |
| 图标体系 | SVG线性图标 | Lucide风格，1.8px stroke-width，统一视觉语言 |
| 应用形态 | PWA | 支持安装到桌面，离线可用，Service Worker缓存 |
| 数据存储 | localStorage → IndexedDB（规划中） | 当前localStorage，规划迁移至IndexedDB突破5MB限制 |
| AI接入 | 开源免费LLM API（Kimi/通义千问） | 意图识别引擎替换，成本可控 |
| 部署 | GitHub Pages | 零服务器成本，全球CDN加速 |

### 2.3 数据架构

**统一数据访问层（DataStore）**：所有模块通过 DataStore 统一接口读写数据，确保数据一致性。

```
localStorage 键值结构：
├── wealth_ct_*              → 财富诊断CT（财务快照）
├── mijieai_daily_tx         → 日常收支交易数组
├── mijieai_schedule         → 日程任务数组
├── mijieai_health_profile   → 健康档案对象
├── mijieai_recipe_collection → 个人菜谱收藏
├── mijieai_behavior_log     → 每日行为日志数组
├── mijieai_mood_log         → 情绪日志数组
├── mijieai_preferences      → 偏好画像对象
└── mijieai_family_edu       → 家庭教育数据
```

**数据导入导出**：全链路支持JSON格式导入导出，数据完全用户自持。

## 六、竞争优势

### 6.1 vs 传统效率工具（Notion/滴答清单/记账APP）

| 维度 | 传统工具 | 个人AI OS |
|------|---------|-----------|
| 数据 | 分散在多个APP | 统一底座，跨模块联动 |
| 智能 | 无/弱（规则型提醒） | 强（LLM驱动的主动决策） |
| 隐私 | 数据存云端 | 100%本地存储 |
| 扩展 | 受限于平台生态 | 模块化自由组合 |
| 成本 | 多APP订阅费 | 单一入口，零服务器成本 |

### 6.2 vs AI助手（Siri/小爱/Alexa）

| 维度 | AI助手 | 个人AI OS |
|------|--------|-----------|
| 交互 | 被动响应 | 主动推送 |
| 理解深度 | 浅层意图识别 | 深层用户画像 |
| 数据关联 | 无法跨APP | 全维度数据打通 |
| 个性化 | 通用化 | 深度个性化（健康+财务+行为） |
| 数据归属 | 厂商控制 | 用户完全掌控 |

### 6.3 核心壁垒

1. **数据飞轮**：用户使用越久，用户画像越精准，推荐越准确，形成正向循环
2. **模块化架构**：每个能力独立成模块，渐进式叠加，竞品无法快速复制
3. **零基础设施成本**：PWA + GitHub Pages + localStorage，运营成本趋近于零
4. **东方养生知识体系**：24节气+食疗+慢病调养，差异化内容壁垒
