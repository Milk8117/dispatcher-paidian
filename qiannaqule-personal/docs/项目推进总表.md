## 二、终态三层架构闭环

> 核心原则：私有数据永不碰云，三层之间数据有序流动，用户按需选用

```
┌─────────────────────────────────────────────────────┐
│              云端服务层（可选增值）                    │
│  公开数据同步 · 模型市场 · 行业知识库 · 协作共享      │
│  （仅存公开数据，私有数据永不触碰）                    │
├──────────────────┬──────────────────────────────────┤
│   本地部署层     │   硬件层（终极形态）                │
│  手机APP/PWA    │  MiRun AI 背夹设备                 │
│  桌面客户端      │  独立算力 · 全模型内置 · 物理离线   │
│  （利用设备算力） │  手机/电脑仅作显示屏                │
├──────────────────┴──────────────────────────────────┤
│              MiRun AI 核心引擎（通用）                │
│  业务逻辑 · 模型调度 · 数据管理 · 插件系统            │
│  （跨平台通用，一套代码跑所有层，不依赖任何平台）        │
└─────────────────────────────────────────────────────┘
```

### 三层定位对比

| 层级 | 定位 | 数据策略 | 适合谁 |
|---|---|---|---|
| **硬件层** | 终极私有形态 | 所有数据全在硬件里，物理断网 | 对隐私要求极高、愿意付费的用户 |
| **本地部署层** | 主流形态 | 私有数据本地存，可选连云端获取公开数据 | 普通用户，平衡便利和隐私 |
| **云端服务层** | 增值服务 | 只存公开内容、行业知识库、用户上传的公开素材 | 需要跨设备同步、协作的用户 |

### 架构预埋原则（开发期必须遵守）
1. **核心引擎独立**：业务逻辑不依赖浏览器/扣子平台，封装为纯JS Core
2. **数据层抽象**：localStorage只是当前实现，预留文件系统/硬件存储接口
3. **模型层抽象**：Provider接口统一，现在调云端API，将来可接本地模型/硬件NPU
4. **UI与引擎分离**：现在是网页UI，将来可接APP、硬件屏幕、语音交互
